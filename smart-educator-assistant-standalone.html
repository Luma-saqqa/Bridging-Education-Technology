Using the Smart Educator's Assistant

Run it in 3 steps

  1. Open the file in a browser (Chrome, Edge, Safari, Firefox). Open it as a real downloaded file — not inside the Claude preview pane.
  2. Add your API key. Paste your Anthropic key (sk-ant-…) into the 🔑 dialog and save. No key? Get one at console.anthropic.com/settings/keys ↗.
  3. Start. Pick a menu card or type a request. The agent asks for curriculum, subject, grade/year and topic, then produces the work.

Day to day

  • Menu or direct request — tap a category, or type a full request like "Year 9 Cambridge IGCSE Biology MCQ on cell division, 15 questions."
  • Language — toggle EN / ع top right; Arabic lays out right-to-left automatically.
  • Export to PDF tags — on a lesson plan, quiz, rubric or feedback, click Export to PDF tags, then Copy the block into your school's Output→PDF tool. It names the template to pick.
  • Reset clears the conversation. 🔑 Key changes or removes your key.

Sharing with colleagues

Send them the file — it's one self-contained HTML file. Each person opens it and enters their own key. The file holds no key, so it's safe to pass around.

Notes & limits

  • A valid key with credit is required to get replies; each person pays for their own usage.
  • The key is stored only in that browser (local storage, in plain text), sent only to Anthropic. A different browser or computer needs it entered again. On a shared or public computer, use 🔑 → Remove when you're done.
  • Won't run inside the Claude preview — always open the downloaded file in a normal browser.
  • No memory between sessions — closing the tab clears the conversation by design.

Troubleshooting

  • Nothing happens / "temporarily unavailable": check the key is entered and the account has credit.
  • Worked, then stopped: the key may have hit a rate or spend limit — check your Anthropic console.
  • Arabic looks misaligned: set the toggle to ع; layout flips to RTL only in Arabic mode.
